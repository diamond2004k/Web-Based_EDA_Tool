# AutoEDA

AutoEDA is a web-based Exploratory Data Analysis platform built using Python and Streamlit. The application automates data cleaning, profiling, visualization, quality assessment, and report generation, enabling efficient analysis of structured datasets.

## Features
- Data Profiling
- Missing Value Handling
- Duplicate Detection
- Outlier Analysis
- Data Quality Scoring
- Interactive Visualizations
- PDF Report Generation

## Tech Stack
- Python
- Streamlit
- Pandas
- NumPy
- Matplotlib
- Seaborn
- Scikit-learn
- ReportLab

## Run Locally

```bash
pip install -r requirements.txt
streamlit run app.py
